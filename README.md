# IPCS GitHub Pages

GitHub Pages 배포용 정적 홈페이지입니다.

- GitHub 저장소의 기존 `docs` 폴더를 이 패키지의 `docs` 폴더로 교체합니다.
- Pages 설정은 `main` 브랜치의 `/docs`를 유지합니다.
- 포트폴리오 링크와 정보는 `docs/portfolio-data.js`에서 수정할 수 있습니다.
