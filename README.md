# IPCS GitHub Pages

GitHub Pages 배포용 정적 홈페이지입니다.

- GitHub 저장소의 기존 `docs` 폴더를 이 패키지의 `docs` 폴더로 교체합니다.
- Pages 설정은 `main` 브랜치의 `/docs`를 유지합니다.
- 포트폴리오 링크와 정보는 `docs/portfolio-data.js`에서 수정할 수 있습니다.
- `docs/CNAME`은 공식 도메인 `ipcontentstudio.com` 연결을 유지합니다.

## 2026-09 신뢰도 개선

- IPCS 공식 이메일과 법인 기본정보를 반영했습니다.
- 김인국 대표이사·홍정완 운영대표·박정환 이사의 경영진 구조와 담당 역할을 반영했습니다.
- 더인벤션랩을 전략적 주주이자 투자 파트너로 구분하고 김진영 대표·김민수 이사의 역할을 표시했습니다.
- 창업기획자 등록 전 단계임을 명확히 알 수 있도록 `창업기획자 등록 준비 중` 상태를 표시했습니다.
- 현재 섹션 메뉴 표시 오류를 수정하고 `PoC` 메뉴를 `G-Planet`으로 명확하게 변경했습니다.
- 주요 행동 버튼을 한글 중심으로 정리하고 이메일 복사 기능을 추가했습니다.
- 보조 정보의 글자 크기와 섹션 간격을 조정해 가독성과 정보 밀도를 높였습니다.
- 포트폴리오에 투자연도와 IPCS 역할을 표시하고 더메디컬브릿지는 베트남 서비스 앱으로 연결합니다.
- 심의도서에서 추출한 G-Planet 고해상도 계획 조감도와 `2026년 12월 오픈 예정` 상태를 표시했습니다.
- 본문·라벨·메뉴 글자 크기와 모바일 줄바꿈을 조정했습니다.
- 앵커 메뉴로 이동할 때 콘텐츠가 잠시 비어 보이는 현상을 보완했습니다.
- 대표 공유 이미지, canonical, 구조화 데이터, sitemap, robots, 404, 개인정보처리방침을 추가했습니다.
